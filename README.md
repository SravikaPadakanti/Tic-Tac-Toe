# 🎀 Tic-Tac-Toe: Kawaii Battle Arena ♡

A beautifully animated Tic-Tac-Toe game featuring anime-inspired aesthetics, complete with adorable characters, celebration effects, and score tracking!

![React](https://img.shields.io/badge/React-18.0+-blue?logo=react)
![License](https://img.shields.io/badge/License-MIT-green)

## ✨ Features

- 🎀 **Anime-Inspired Design** - Cute characters "SAKURA" (X) and "MIZUUMI" (O) with kawaii styling
- 🌸 **Animated Background** - Falling cherry blossoms, floating clouds, and particles
- 🎯 **Winning Detection** - Visual highlights for winning combinations with celebration effects
- 📊 **Score Tracking** - Keep track of wins and draws across multiple games
- 💫 **Celebration Particles** - Sparkle effects and confetti animations on victory
- 🎨 **Gradient UI** - Beautiful pastel colors with glassmorphism effects
- 📱 **Responsive Design** - Works seamlessly on desktop and mobile devices
- ⚡ **Interactive Buttons** - Smooth animations and hover effects

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn package manager

### Installation

1. Clone the repository
```bash
git clone https://github.com/SravikaPadakanti/Tic-Tac-Toe.git
cd Tic-Tac-Toe
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npm start
```

4. Open your browser and navigate to `http://localhost:3000`

## 🎮 How to Play

1. **Start Game** - The game begins with SAKURA (🌸) as X
2. **Take Turns** - Click on any empty square to place your mark
3. **Win Condition** - Get three in a row (horizontally, vertically, or diagonally) to win
4. **Draw** - If all squares are filled with no winner, it's a draw
5. **Score Tracking** - Wins and draws are automatically tracked
6. **New Game** - Click "NEW GAME ♡" to play again
7. **Reset Scores** - Click "RESET ALL ⭐" to clear all scores

## 🎨 Customization

### Colors
Edit the gradient backgrounds and colors in `App.jsx`:
```jsx
background: 'linear-gradient(135deg, #ffd1dc 0%, #ffb6c1 25%, #e6e6fa 50%, #b0c4de 75%, #add8e6 100%)'
```

### Animations
Modify animation speeds and effects in the `<style jsx>` section:
```jsx
@keyframes fall {
  // Customize cherry blossom fall animation
}
```

### Character Names
Change SAKURA and MIZUUMI to your preferred names in the JSX markup.
